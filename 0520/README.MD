# 강의 발표 및 토론

## 타 조별 프로젝트 탐색 및 평가

다른 조에서 진행한 프로젝트를 탐색하고 구현 방식, 기능 구성, 사용자 인터페이스(UI) 및 데이터베이스(DB) 설계에 대해 분석하였다. 또한 각 프로젝트의 장점과 개선사항에 대해 토론하며 프로젝트 개발 과정에 대한 이해를 높였다.

---

# 프로젝트 수행 내용

## 웹 사이트 구축 및 설계

* JSP 기반 웹 사이트 설계 및 구현
* 사용자 인터페이스(UI) 구성
* 페이지 구조 설계 및 기능 구현

## 서버 환경 구축

* Apache Tomcat 서버 설정 및 운영
* 프로젝트 배포 환경 구성

## 데이터베이스(DB) 구축

* 회원 정보 저장을 위한 데이터베이스 설계
* 로그인 기능 연동
* 회원 정보 DB 구조 개선 및 수정
* 추가 테이블 및 데이터 구성

## API 활용

* Google API 연동
* API 기능 추가 및 동작 수정
* API 데이터 활용 기능 구현

## 웹 디자인 및 기능 개선

* 이미지 기능 추가 및 구현
* 웹 사이트 애니메이션 효과 적용
* 사용자 경험(UX) 향상을 위한 화면 구성 수정

## 성능 분석

* 벤치마크 자료 수집
* 성능 측정 및 분석
* 웹 서비스 최적화 방안 검토

---

# 프로젝트 결과

JSP, Tomcat, Database, Google API 등을 활용하여 웹 사이트를 구축하였으며, 로그인 기능과 회원 관리 기능을 구현하였다. 또한 다양한 웹 기능과 애니메이션 효과를 적용하여 사용자 경험을 향상시키고, 벤치마크 자료를 기반으로 성능 분석 및 개선 작업을 수행하였다.

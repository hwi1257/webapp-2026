1. JSX(JavaScript XML)의 활용
HTML과 자바스크립트를 섞어서 쓸 수 있는 편리함을 익혔습니다.

학습 포인트: 반드시 하나의 부모 요소(<div>나 <>)로 감싸야 오류가 나지 않는다는 점을 확인했습니다.

Babel이 우리가 쓴 코드를 브라우저용 자바스크립트로 변환해 준다는 원리를 이해했습니다.

2. 컴포넌트(Component) 중심 설계
전체 페이지를 한 번에 만드는 게 아니라, 레고 블록처럼 UI를 조각내어 조립하는 방식을 배웠습니다.

주의사항: 컴포넌트 이름은 꼭 **대문자(Pascal Case)**로 시작해야 리액트가 인식할 수 있습니다.

현재는 클래스형보다 훨씬 간결한 함수형 컴포넌트가 표준으로 쓰인다는 것을 배웠습니다.

3. Props(속성) 데이터 전달
부모 → 자식: 부모 컴포넌트가 자식에게 데이터를 넘겨주는 '전달자' 역할을 한다는 점이 핵심입니다.

규칙: 자식은 받은 데이터를 읽을 수만 있고 직접 수정할 수 없는 읽기 전용입니다.

중괄호 {}를 사용해 문자열, 숫자, 객체 등 다양한 데이터를 넘겨주는 실습을 진행했습니다.

4. 리액트의 핵심: Virtual DOM
리액트가 빠른 이유인 가상 DOM의 원리를 학습했습니다.

화면 전체를 새로고침하는 대신, 변경된 부분만 찾아내서(Diffing) 업데이트하는 효율적인 렌더링 과정을 이해했습니다.

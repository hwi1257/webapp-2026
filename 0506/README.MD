📚 Share-IT: 학과 전공 자원 공유 및 대여 관리 플랫폼
학과 내 자원 선순환을 통한 학생 복지 및 협력적 학습 환경 조성 프로젝트

1. 프로젝트 개요 (Overview)
1.1 기획 배경 및 목적
대학 전공 서적과 실습 기자재는 높은 구매 비용에 비해 실제 사용 기간이 짧아 학생들에게 경제적 부담이 됩니다. 본 플랫폼은 이러한 자원들을 학우 간에 서로 공유하고 대여할 수 있는 시스템을 제공하여, 불필요한 지출을 줄이고 학내 자원의 활용도를 극대화하기 위해 기획되었습니다.

1.2 핵심 목표
자원 공유 활성화: 방치되는 전공 자원의 선순환 구조 구축.

경제적 부담 완화: 전공 도서 및 실습 장비 구매 비용 절감을 통한 학생 복지 실현.

협력 문화 조성: 공유 경제 모델을 기반으로 한 학과 내 상호 도움 문화 정착.

2. 주요 서비스 기능 (Key Features)
🔐 인증 및 보안 관리
세션 기반 사용자 관리: 회원가입 및 로그인 기능을 제공하며, 서버의 세션(Session) 관리 기술을 통해 사용자 인증 상태를 안전하게 유지합니다.

📦 자원 등록 및 정보 연동
자율 등록 시스템: 사용자가 보유한 도서나 장비의 제목, 상세 설명, 보존 상태를 직접 등록하여 공유할 수 있습니다.

외부 도서 데이터 연동: 책 검색 시 외부 API와 통신하여 실제 도서의 표지 이미지와 가격 정보를 실시간으로 파싱해 제공함으로써 정보의 정확도를 높였습니다.

🔄 스마트 대여 및 예약 프로세스
실시간 상태 제어: 각 자원의 상태를 '대여 가능(AVAILABLE)', '예약 중(RESERVED)', '대여 중(BORROWED)'으로 구분하여 체계적으로 관리합니다.

대여 및 반납 자동화: 사용자의 요청에 따라 서버가 로그인 상태를 검증한 후 데이터베이스의 상태값을 즉시 업데이트하고, 대여 및 반납 시간을 기록하여 투명한 관리 이력을 생성합니다.

예약 시스템: 현재 대여 중인 물품에 대해 사전 예약을 신청할 수 있는 기능을 제공합니다.

3. 시스템 아키텍처 (Architecture)
본 프로젝트는 사용자 중심의 동적 웹 시스템으로 설계되었습니다.

동작 원리: 사용자의 브라우저 요청을 Apache Tomcat 서버가 수신하여 비즈니스 로직을 처리하며, 모든 데이터는 MySQL 데이터베이스에 영속적으로 저장됩니다.

데이터 처리: 서블릿(Servlet) 기술을 활용하여 사용자의 이벤트에 따라 데이터 상태를 변경하고, 외부 API를 호출하여 추가적인 정보를 보완하는 통합 프로세스를 구축했습니다.

4. 데이터베이스 구조 (Database Design)
효율적인 데이터 관리를 위해 세 가지 핵심 영역으로 데이터를 구분하여 설계했습니다.

사용자 계정 정보: 사용자 식별자, 성함, 인증 비밀번호 등을 관리합니다.

공유 자원 정보: 아이템별 고유 식별자, 명칭, 현재 대여 상태, 소유자 정보를 관리합니다.

트랜잭션 이력: 대여 및 반납 기록, 대여자 정보, 이용 자원 정보를 포함한 모든 이력을 관리합니다.

5. 기대 효과 (Anticipated Impact)
학생 복지 증진: 전공 서적 구매 비용의 실질적 절감을 통해 학생들의 학업 집중도 향상에 기여합니다.

자원 활용 효율화: 고가의 실습 장비 활용도를 높여 학과 내 자산 운영의 효율성을 증대시킵니다.

기술적 역량 입증: WAS(Tomcat)를 통한 동적 요청 처리, 데이터베이스 연동, 외부 API 활용 능력을 실제 비즈니스 모델에 적용하여 구현했습니다.
